# Still Alive Revived

Still Alive Revived is a 2D portal puzzle game for the browser. It updates the original Still Alive JS game by Christophe "t4ils" with new graphics, an updated interface, and modernized architecture.

[Play the game](https://splitbrain.github.io/stillalive/).

## Run the game locally

```sh
npm ci
npm start
```

Open http://localhost:8080 in your browser.

## Check changes

Run `npm run lint`, `npm run typecheck`, and `npm run test:unit` to check the code. Run `npm test` for the browser tests.
