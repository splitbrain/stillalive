About

Still Alive Revived is a modernized version of the original Still Alive game made by t4ils.

The game is available under the GNU Affero General Public License on GitHub.

History

In 2007, Valve released Portal. It was a huge success (I'm making a note here). But I wouldn't play it until 2011, when Valve released Portal 2.

What I did play first was a little indie game for the Nintendo DS called Still Alive, a game inspired by a fan project named Portal: The Flash Version. The idea was simple: what if Portal, but 2D?

Since I hadn't played the original, Still Alive was the first time I was thinking in portals. And I loved it.

Now, nearly twenty years later, I remembered this game and wondered what had happened to it.

The original website is long gone, but with a bit of Internet sleuthing, I learned that t4ils, the developer of Still Alive, had not only made this version for the Nintendo DS, but had also ported it to the Wii. And, to my surprise, he had also made a web-based version called Still Alive JS. He even made it open source!

Even though the website no longer exists, the Wayback Machine had archived enough of it to recover the game's JavaScript source code. And that's how Still Alive Revived was born.

Technology

My goal with the revived version is to keep the gameplay and the graphical design of the original, but to bring it into the modern age.

Just as t4ils' original game could be revived 15 years later, I wanted my version to be as independent as possible from the whims of modern web technology. So I decided to use only browser technologies and not to rely on any fancy build pipelines or libraries. As in t4ils' original game, a loader fetches all the necessary files first. Only this time, it fetches ES modules, web components and SVGs instead of jQuery and PNGs.

The original game and physics engine is still in use. But instead of rendering all graphics and UI elements onto a canvas, I moved the UI to HTML and CSS. This allows for a more flexible layout and makes it easier to adapt to different screen sizes.

The original game sprites and graphics were designed with the DS in mind, so their resolution was very low and not suitable for larger screens. For Revived, all graphics were redrawn as SVGs, with the original graphics as reference. Where the original was too pixelated, I used the decorations of the accompanying website as the style guide, for example when redoing the character sprite.

The old game used audio objects to play sound effects. This was a very limited approach, as each sound could only play once at a time. With the modern Web Audio API, I was able to replace the old sound effects, whose license was unclear, and add many more that can play and mix at the same time, together with background music. As a result, the new game sounds more lively.

Still Alive Revived is a testament to what modern browser technology can do. But it's also a testament to what agentic coding can achieve. I laid down the ground rules, made the architectural decisions, and reviewed and directed the conversion, while Claude did all the grunt work. I would not have been able to tackle a project like this in my spare time without the help of AI.
